# Walk in Light

A personal progress console for building the **Walk in Light** media universe: a three-film story, educational YouTube series, Christian-worldview reviews of anime and film, and hardstyle music production. A clean cyberpunk productivity UI with a strong blue emphasis and a cross at the center.

It is a free, installable web app (PWA) for iPhone. No App Store, no developer account, no server, no cost. All data stays on the phone.

## Install on your iPhone (free)

1. Host the files (see **Hosting** below). You get a URL like `https://<you>.github.io/<repo>/`.
2. Open that URL in **Safari** on the iPhone.
3. Tap **Share** → **Add to Home Screen** → **Add**.
4. Open it from the home screen. It runs full screen and offline.

Your progress lives in the app's local storage on that phone. Export a backup from **Settings** once a month; it uses the iOS share sheet so you can save straight to Files or Drive.

## Hosting (GitHub Pages, free)

This repository is a static site. In **Settings → Pages → Build and deployment**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, and save. A minute later the site is at `https://glen-skahill.github.io/walk-in-light/`.

Public repositories get GitHub Pages for free. A private repository needs a paid plan for Pages, so keep the repo public (there is nothing private in the code; your data never leaves the phone).

## How the app is organised

- **Home**: verse of the day, level, points and streak, the *I have 15 / 45 / 90+ minutes* filter, **Next up** (one task per project), the idea **Inbox**, project progress.
- **Studio**: one-time setup in tiny steps: the YouTube channel, brand kit, free tools, folders and backup, the recording corner.
- **Story** (The World): trilogy spine, world rules, characters, Film I outline and draft, Films II and III, short films, organizing; a **Scripts** pipeline; the **Bible** (characters, locations, factions, lore, events, themes, props).
- **Teach**: series plan, then Episode 1 from script to publish, then Episodes 2 and 3; an **Episodes** pipeline.
- **Lens**: the four-question worldview lens, format and template, Review #1 start to finish, cadence; a **Reviews** pipeline.
- **Music** (Hardstyle): free setup, ears first, the kick, enough theory, the first drop, arrangement, mix, master and release, keep learning; a **Tracks** pipeline.
- **Playbook** (book icon): solo-creator practices. **Settings** (gear): glow, text size, calendar reminder, export/import, content merge, reset.

Every task has a size (S 15 min, M 45, L 90+), a short "How", a list of **tiny steps** you tick off one by one (ticking the last one marks the task done), your notes, and a pin for the week's focus. Tapping the box cycles to do → in progress → done. Deleting anything takes two taps.

## Updating content later

Edit `js/seed.js`, bump `version`, bump `CACHE` in `sw.js`, push. On the phone, **Settings → Merge latest content** adds the new steps and refreshes guides on steps you have not edited, keeping all progress.

## Sync and daily briefs

**Settings → Sync** saves your progress to one private GitHub repository (`data/state.json`) every few seconds after a change, and pulls a newer copy when the app opens. It needs an empty private repo (for example `walk-in-light-data`) and a fine-grained personal access token with *Contents: Read and write* on that repo only. The token is stored on the phone and is stripped from the uploaded file and from exports.

With sync on, scheduled Claude sessions read that file and push a three-line brief to your phone: yesterday's completed steps, today's task, and a verse. The schedule lives in Claude's scheduled tasks, not in this repo.

## Reminders

iPhone web apps cannot schedule their own notifications without a push server. **Settings → Add daily reminder** generates a repeating calendar event with an alert; or set a daily reminder in the iOS Reminders app. See `docs/QUESTIONS.md` for the options if you want real push notifications.
